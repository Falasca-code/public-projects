# Branding por deployment profile

O branding deve ser configuração do deployment, não fork por cliente. Valores previstos: `APP_NAME`, `APP_SHORT_NAME`, `APP_DESCRIPTION`, `APP_URL`, `BRAND_LOGO`, `BRAND_LOGO_DARK`, `BRAND_FAVICON`, `BRAND_PRIMARY` e `BRAND_ACCENT`.

Aplicar a mesma fonte no login, sidebar, navbar, favicon, title, loading, erros, rodapé, e-mails, exports, metadata e manifest/PWA. Enquanto a migração não for feita no build do frontend, `Farol` é o default explícito.
